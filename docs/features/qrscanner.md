# Spoolman QR Scanner Support

Support for QR scanners is provided through
[SET_NEXT_SPOOL_ID](../klipper/internal/spool.md#AFC_spool.AFCSpool.cmd_SET_NEXT_SPOOL_ID).

A USB QR code scanner implementation [afc-spool-scan](https://github.com/AFCProject/afc-spool-scan) is available to
install on the klipper host.
